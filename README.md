# NOeSIS 01 HD 简体中文汉化补丁（非官方）

《NOeSIS-诉说谎言的记忆之物语（超高清FHD版）》Steam Playtest（app 2151750，Utage / Unity 2019.4）的同人汉化补丁。需自备正版游戏本体，补丁不包含游戏本体文件。

## 汉化内容

- 全部剧情对白（13,708 条）简体中文
- 说话人名牌贴图（中文重绘）
- 系统 UI 文本

文本来源见 Issue #1《文本来源说明》。

## 安装

1. 下载 Release 的补丁包并解压。
2. 运行一键安装脚本（会自动定位 Steam 游戏目录、先备份原文件再打补丁）；或手动：将补丁包内文件按说明覆盖到游戏目录 `NOeSIS HD_Data/` 下（覆盖前请自行备份同名原文件）。
3. 从 Steam 正常启动游戏即可。

还原：安装脚本备份的原文件改回原名即可，或用 Steam「验证游戏文件完整性」恢复。

## 已知问题

- 纱奈姬篇为 HD 版新增章节、无旧版汉化底本，全篇为机器翻译新译，已经过一轮复核，质量仍可能弱于其他章节，欢迎提 Issue 指正具体条目。

## 自行构建

仓库内的 `translations.json` 为全量译文，`scripts/` 为回写脚本。以正版游戏的 `sharedassets1.assets` 为底，用 splice 脚本将译文写回即可得到与 Release 相同的成品（校验值见 Release 说明）。
